# Pawzzles Image Prompt Reference

Use this structure when manually writing or reviewing Pawzzles image prompts.

## Required Fields

- Exact image size: 1080x1080
- Post type
- Layout direction
- Headline text
- Supporting text
- CTA text
- Colour palette
- Visual elements
- Dog image notes
- Product image notes
- QR image notes
- Negative instructions

## Brand Direction

- Warm cream or soft ivory background
- Teal blue and Pawzzles orange accents
- Rounded shapes, soft corners and clean premium spacing
- Paw print doodles, heart doodles and tiny sparkle marks
- Playful handwritten-style headline
- Clean sans-serif supporting text
- Dog enrichment, natural toy and happier dog feeling
- Clear QR code placement when used

## Negative Instructions

- Avoid clutter
- Avoid unreadable text
- Avoid off-brand colours
- Avoid generic pet shop styling
- Avoid dark, harsh or discount-heavy layouts
